# 🚀 Custom strategy for zapret by @Emergeflow

Кастомная стратегия обхода блокировок для сборки **Zapret** от разработчика [Flowseal](https://github.com/Flowseal).

Оптимизирована для стабильной работы популярных сервисов и игровых серверов в РФ.

---

## ✨ Поддерживаемые сервисы

* 🎥 **YouTube** (просмотр в 4K без задержек и быстрая загрузка превью)
* 💬 **Discord** (голосовые каналы и текстовые чаты)
* 🎮 **Minecraft** (европейские сервера: Hypixel, Mineman и др., стандартный порт `25565`)

---

## 🛠️ Инструкция по установке

1. Скачайте актуальную сборку zapret со страницы под названием [**«Flowseal Releases»**](https://github.com/flowseal/zapret-discord-youtube/releases) и распакуйте её.
2. Скачайте файл `general (Emergeflow) v1.1.bat` из раздела под названием [**«Releases»**](https://github.com/Emergeflow/Custom-strategy-for-zapret/releases).
3. Поместите файл `general (Emergeflow) v1.1.bat` в корневую папку Zapret (рядом с файлом `service.bat`).
4. Запустите `general (Emergeflow) v1.1.bat` от **имени администратора**.

---

## 📝 Переименование `.bat` файла

При скачивании из релизов GitHub файл может называться `general.Emergeflow.v1.1.bat`. 

Если вы хотите, чтобы имя файла полностью соответствовало стилю оригинальных стратегий zapret, просто переименуйте его в:
`general (Emergeflow) v1.1.bat`

---

> [!WARNING]
> **Важное примечание о совместимости:**
> 
> Эффективность работы стратегии зависит от вашего провайдера, региона и оборудования ТСПУ/DPI. Данная стратегия может подходить не всем. Если у вас возникли проблемы со стабильностью подключения, **рекомендуется попробовать альтернативные стратегии из сборки Zapret**.

## ⚙️ Технические особенности стратегии

* **Использование паттерна Google:** Подмена TLS ClientHello на `tls_clienthello_www_google_com.bin`.
* **Смещение границ:** Позиционирование `split-pos=2` и `seqovl=652` для обхода ТСПУ.
* **Fooling-методы:** Комбинация `md5sig,ts` для сбивания систем анализа трафика.
* **Оптимизация:** Ограничение повторов фейков (`repeats=6`) для сохранения минимального пинга.
